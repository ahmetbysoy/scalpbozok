# 🐆 BOZOK PRO — Orderbook Intelligence & Market Microstructure Analysis System

**BOZOK PRO** is a web-based high-frequency orderbook intelligence, market microstructure, and orderflow analytics terminal built with React, TypeScript, and Tailwind CSS.

## 🎯 Key Features

- **📊 BOOK View**: Real-time Orderbook Ladder with Bid/Ask depth bars, focus price highlight, active Heatmap depth layers (Liquidity, Walls, Trades, Liq Pools), and strong wall detector cards.
- **🕯️ FLOW View**: Footprint flow candles chart, Point of Control (POC) gold markers, volume delta metrics, and footprint price cell distributions.
- **📚 DEPTH View**: Order Book Imbalance (OBI) gauge, Cumulative Volume Delta (CVD) tracking, VPIN toxicity meter, and live trade tape stream.
- **🎯 SIGNALS View**: Real-time pattern signal feed stream (Absorption, Strong Wall, Spoofing/Wall Pull, Short Liquidation Cascade), directional filters (Bull 🟢, Bear 🔴, Warning ⚠️), confidence threshold slider, and rolling signal verification accuracy tracking.
- **📍 LEVELS View**: Meta-Synthesis Narrative card, MetaStrategy Trade Plan (Entry, Stop Loss, TP1, TP2, Risk/Reward ratio, Kelly Position Sizing), Micro Optimizer interactive risk/leverage calculator, and strategy performance equity history chart.
- **🌐 MARKETS View**: Multi-exchange orderbook comparison (Binance, Bybit, OKX, MEXC), Live Arbitrage Skew opportunity scanner with lead venue indicators and bps deviation alerts.
- **⚙️ SETTINGS View**: Sensitivity presets (Muhafazakâr, Normal, Agresif), Theme selector (Professional Dark, Neon Cyber, Minimal Light), Colorblind mode (Okabe-Ito palette), and sound & voice toggles.

## 🚀 Getting Started

```bash
npm run dev
```

Runs the application in development mode on port 3000.

```bash
npm run build
```

Builds the production bundle.
